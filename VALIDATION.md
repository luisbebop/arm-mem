# arm-mem validation

Checked on 2026-10-18 with Node 22.23.1, SQLite 3.51.3, TypeScript 7.0.2,
and js-tiktoken 1.0.21.

The package and CLI are `arm-mem`. Set `ARM_MEM_DB` to choose a database file;
the default is `arm-mem.db`. The strict build and all 14 offline tests passed.

- TypeScript strict build passed.
- All 14 offline tests passed, covering persistence across processes, concurrent
  workers, task priority, expired leases, stale writes, retry limits, atomic memory
  proposals, retirement, Unicode chunking, online backup, retrieval, and the HTTP
  adapter's Flash/max settings and error handling.
- An independent comparison against the frozen Python benchmark matched **40/40
  questions across 20 conversations**, with **948 selected records**: identical
  content, record order, and evidence-unit totals. It used temporary SQLite backups;
  the original benchmark databases and source files were not edited.
- One live Flash/max request passed: a new task recalled a supplied SQLite fact,
  answered correctly with its memory ID, and committed the answer. Returned usage
  was 132 input tokens and 46 output tokens (including 34 reasoning tokens). The
  temporary database was removed. No API key or reasoning text is bundled.

## Full BEAM answering and grading

On 2026-10-18 arm-mem completed a full run of 40 BEAM 100K
contradiction-resolution questions across 20 conversations. Answers used DeepSeek
Flash/max; the unchanged judge was GPT-5.6 Luna/none, with the original four rubric
items, schema and score thresholds. Scores include partial credit.

| Configuration | Score |
| --- | ---: |
| TypeScript package, default prompt | **77.81%** |
| Original benchmark prompt, fresh control | 70.94% |

The TypeScript Store imported all 11,244 original raw records and their provenance
into 20 fresh databases. Retrieval matched the original exactly on every question.
The package's default `deepseek()` function supplied the answers; its code and
prompt were frozen before running. The control used the original benchmark's
category-specific prompt and evidence wrapper. No reference answers, rubric items,
or annotated source labels entered either reader.

| Rubric criterion | Package | Control |
| --- | ---: | ---: |
| Recognizes contradiction | 83.75% | 100.00% |
| First conflicting claim | 81.25% | 82.50% |
| Second conflicting claim | 80.00% | 80.00% |
| Clarification criterion | 66.25% | 21.25% |

The higher aggregate comes primarily from the clarification criterion; recognition
is lower. This compares answering configurations on identical memory. It does not
establish a retrieval improvement, uniform improvement, or general superiority.
The existing judge's ambiguity around clarification remains, and these are
previously inspected development questions.

Independent auditing verified all 80 answers, 320 rubric grades, eight judge
controls, request hashes, raw-score conversions, memory contents and usage costs.
All 408 calls in the reported pass succeeded on their first attempt.

The reported pass cost approximately **$0.1604** including both readers and judging.
The package's 40 answers alone cost **$0.0806**. A second pass had completed and a
third had started before the user requested one pass only. Extra work was stopped;
only the first pass is reported, and later logs remain saved. Total cost from all
saved usage before stopping was **$0.2975**; interrupted requests may have additional
charges without returned usage.

The standalone package excludes benchmark conversations and third-party prompts.
Its offline tests remain reproducible without API keys or benchmark data.

## Comparison with OptMem and Past's published result

The saved experiments put arm-mem well ahead of the two
[OptMem](https://github.com/VictorTaelin/OptMem) configurations
tested on this subset, and numerically close to Past's published result:

| System / configuration | Answer model | Score | Run basis |
| --- | --- | ---: | --- |
| arm-mem, default prompt | DeepSeek Flash / max | **77.81%** | One run |
| OptMem, native wake/search context | DeepSeek Flash / max | 57.40% | Mean of 58.13%, 57.50%, 56.56% |
| OptMem, selected notes after search | DeepSeek Flash / max | 51.67% | Mean of 54.38%, 50.00%, 50.63% |
| Past, published reference | GPT-5.6 Luna / none | 78.13% | External published run |

arm-mem's score is about **20.4 percentage points above** the stronger OptMem
variant and about **0.3 points below** Past's result. Both comparisons concern
the same 40-question BEAM 100K contradiction-resolution subset across 20
conversations. These are partial-credit rubric scores for this ability.

The OptMem experiments used its unchanged
[pinned implementation](https://github.com/VictorTaelin/OptMem/tree/1fb164cf39028047781f72ac3bb1e5a691c1dcb0).
Our adapter used Flash/max to extract notes from complete conversation archives,
invoke native compression, and search the resulting memory. This was batch
ingestion, not live turn-by-turn note-taking. One memory build and retrieval
trajectory were reused across three fresh answer-and-grading runs per variant.
The stronger variant supplied all observed native wake/search rows; the other
supplied agent-selected notes. The 57.40% and 51.67% figures are our adapter
results, not published OptMem leaderboard scores.

Those experiments used the original benchmark answer prompt and GPT-5.6 Luna/none
judge. Their accompanying memory baseline, using the same retrieval as arm-mem
but the original prompt, averaged **71.88%**, also above both OptMem variants.
arm-mem's later **77.81%** run used its default prompt. The difference cannot be
attributed solely to memory storage or retrieval.

[Past's published benchmark](https://past.dev/benchmarks), checked on 2026-10-18,
reports **78.13%** for contradiction resolution at 100K, using GPT-5.6 Luna for
both answering and judging. Its overall 100K result across all ten abilities is
92.08%; arm-mem has not been evaluated here on that complete 400-question split.

[Past](https://past.dev/) sells a managed memory API through usage credits,
subscriptions, and enterprise agreements. Its [pricing](https://past.dev/pricing),
checked on 2026-10-18, starts with a $0/month pay-as-you-go plan and credit packs
from $30 per 100,000 credits; Flex is $99/month; Enterprise has custom pricing.
These commercial service prices are separate from the model-call costs of our
experiments. The [README](README.md#tested-result) includes plan allowances.

Different prompts, model choices, ingestion procedures, and run counts make this
a descriptive comparison. The substantial observed OptMem gap applies to these
tested configurations. Nearness to Past's number does not establish statistical
equivalence or matching performance across BEAM. No new model runs were made to
produce this comparison; it summarizes the saved results.
